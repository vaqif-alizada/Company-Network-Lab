# Company-Network-Lab


## 📌 Project Overview
This repository contains a multi-site enterprise network topology designed in **Cisco Packet Tracer** as part of my practical preparation for the **Cisco Certified Network Associate (CCNA)** certification. 

The project focuses on building a highly redundant, scalable network infrastructure spanning a HQ, redundant ISP edge connections, and remote branch locations. Specific architectural design patterns were deliberately chosen to demonstrate networking concepts.
